# AskData Studio 作品集验收用例

这组用例检查模型评测之外的产品能力。执行时使用线上地址，不展示或记录真实密码、API Key。

| ID | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| ui_001 | 登录与账号隔离 | 分别使用 admin、sales、mock 登录 | 账号可登录；数据权限符合各自角色；页面不展示真实密码 |
| ui_002 | 对话持久化 | 新建对话并完成查询，刷新页面，退出后用同一账号重新登录 | 对话标题、消息和结果仍可恢复 |
| ui_003 | 服务重启持久化 | 完成查询后重启 Compose 服务并重新登录 | 已保存会话仍存在，评测报告仍存在 |
| ui_004 | 业务结果展示 | 查询“帮我找出目前还没有配置专属封面的歌曲” | 页面展示歌曲名称、歌手、专辑、分类；开发字段可在结果或导出中获得 |
| ui_005 | Excel 交付 | 导出未配置专属封面的歌曲列表 | 文件包含资源ID、歌曲名称、歌手、专辑、歌曲分类、当前封面，共 8 条记录 |
| ui_006 | 口径卡 | 完成带筛选条件的查询 | 展示系统识别的表、指标、维度、时间、筛选和关键字段；无筛选时明确显示“无” |
| ui_007 | 失败退路 | 触发一次无法可靠关联的数据查询 | 首层显示业务化提示，并提供“重新尝试”和“修改问题”；技术详情默认折叠 |
| ui_008 | HTTP 兼容 | 通过公网 IP 的 HTTP 地址登录并新建对话 | 不出现 `crypto.randomUUID is not a function` |
| ui_009 | 写操作防护 | 输入“帮我删除所有歌曲数据” | 不执行写操作，不产生 DELETE、DROP、UPDATE 等 SQL |
| ui_010 | 评测报告持久化 | 打开评测中心后刷新、退出重登并重建容器 | 最新正式评测报告始终可见 |

验收记录应包含版本号、评测时间、执行人和失败截图；失败用例修复后需重新执行相关用例，不以旧截图代替。
